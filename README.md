## Assignment Overview

This assignment focuses on practicing fundamental and intermediate TypeScript concepts through eight problem-solving tasks and two blog.

The tasks cover:

1. Optional parameters and default value handling.
2. Union types and type narrowing.
3. Readonly tuples and tuple manipulation.
4. Generics and rest parameters.
5. Interfaces and array filtering.
6. Generics with keyof and indexed access types.
7. Object-Oriented Programming (OOP), including inheritance and access modifiers.
8. Asynchronous programming using Promises, resolve, reject, and setTimeout.

Objective: To strengthen TypeScript fundamentals, improve problem-solving skills, understand type safety and apply these concepts through practical coding exercises.

2. [Access Modifiers in OOP](accessModifiers-in-OOP.md)
